HiPDF 使用说明

让文档工作，轻一点。适用于 macOS 14 及以上版本的 Apple Silicon Mac。

开始处理

  1. 从工作台选择工具，或用 ⌘ K 搜索。
  2. 拖入文件，或点“添加文件”。合并时用队列箭头调整文件顺序。
  3. 在右侧设置参数；页码范围如 1-3,5，留空通常代表全部页面。
  4. 点击“开始处理”。结果另存到独立文件夹，可预览或在 Finder 中显示。

输出默认位于 ~/Documents/HiPDF。左下角可更换保存位置。每次处理保留原件，取消或失败会清理该次临时输出。

配置 AI 服务

  1. 打开“设置 → AI 服务”（⌘ ,）。
  2. 填写 API 地址，例如 https://api.openai.com/v1，也可填兼容服务地址或本机 http://localhost:1234/v1。
  3. 填写 API Key 与准确的模型名。本机免认证服务可留空 Key。
  4. 点击“测试连接”，测试只发送检查文本；成功后保存。
  5. 打开 AI 摘要或 PDF 翻译，选择文件和输出参数。

支持 OpenAI Chat Completions 协议。高级选项可调整超时、每段字数、输出 Token 上限、max_tokens/max_completion_tokens 以及是否发送 temperature。API Key 仅保存至 macOS 钥匙串；普通 PDF 操作离线完成，AI 工具仅在启动后发送文档文字至指定服务。

长文会完整分段处理。摘要会再合并，翻译支持尽量保留原版面与重新排版两种模式。若原版面无法容纳译文，切换重新排版。扫描件先在本机 OCR。

页面和编辑

点击缩略图预览页面，勾选页码选择范围。排列 PDF 可以输入 3,1,2,2，表示倒换页序并重复第 2 页。

编辑、裁剪、签名、表单和密文工具支持在预览中拖动框选。编辑前选择文字、图片、矩形、高亮或手绘模式；右侧可撤销或清空选区。关闭“框选”后可以正常选择 PDF 文字。

裁剪只改变可见范围，不能用于删除敏感信息。密文工具实际删除文字和图像区域，并清理隐藏内容、元数据和附件；输出后请复核全部敏感区域。

表单和签名

表单工具可读取已有字段，填写后保持可交互；勾选“平面表单”会固定字段。创建模式先选字段类型，再框选位置。自动检测适用于有清晰矩形边框的文档。

签名支持文字、签名图片、手绘笔迹和 PKCS#12 证书。视觉签名不等于证书签名；证书签名需要自己的 .p12/.pfx 和密码。离线版本不提供云端邀请、身份核验或可信时间戳。

扫描、转换与工作流程

扫描工具可连接 macOS 图像捕捉支持的扫描仪，也可导入照片或 TIFF。OCR 使用系统 Vision。Office 引擎随应用提供，无需安装 Python 或 Microsoft Office。

Word/PPT 输出会尽量重建可编辑内容；复杂字体、多栏排版和表格请校对。PDF/A 按 2b 模式导出，正式归档前需要独立合规校验。PDF 转 Markdown 完全本地运行，不需要 AI。

“工作流程”可添加多个 PDF 工具，逐步配置、排序、保存或导出模板。每一步的输出交给下一步。模板不保存密码。最近任务页面可定位之前的输出。
